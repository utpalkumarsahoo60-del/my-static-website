## 🚀 Deployment

The static website is hosted on Amazon S3.

GitHub Actions automates deployment whenever changes are pushed to the `main` branch.

### Deployment Workflow

1. Developer updates website source code.
2. Code is pushed to GitHub.
3. GitHub Actions triggers the deployment workflow.
4. Website files are uploaded to the AWS S3 bucket.
5. Updated website content becomes available online.
